\opening{Dear Professor H\"ullermeier,}

Re: revision of manuscript \nolinkurl{1e58c388-d7ec-4084-b792-df20a48e3e75},
``Baseline-Relative Predictability Horizons for Cross-Domain Forecast Evaluation.''

We are attaching the revised version of the manuscript, as well as a detailed point-by-point response. The main changes are:

\begin{itemize}[leftmargin=*,itemsep=0pt]
\item \textbf{Definitions and usage.} In the definition of the relaxed horizon, it is now specified that non-positive steps can remain within its range; additionally, a new subsection explains what the relaxed and strict horizons contribute to fixed-horizon summaries, as well as which aspects they do not determine. It also analyzes why using descriptors to select horizons dynamically would require a prospective or nested evaluation, since otherwise there is a risk of incurring adaptive selection bias.
\item \textbf{Presentation.} Figures 1 and 2 were redesigned, all figures are cited, and units are indicated.
\item \textbf{Alternative baseline.} We added a sensitivity analysis based on seasonal persistence with exactly matched support for the four domains.
\item \textbf{ARIMA.} The order $(2,0,0)$ was fixed \emph{a priori} and was not selected using ACF or information criteria. As noted in our response, we now report an order diagnostic based on the AIC and the ACF/PACF plots in a new appendix, and we present this check as an illustration of the sensitivity of the model class.
\end{itemize}

\textbf{Corrections to previously reported results.} While preparing the revision, we detected and corrected three errors in the data presentation, all of them described in the response letter. (i) In the text related to PM$_{2.5}$, it indicated $H^*(\mathrm{strict})=13$, a value derived from a moving-average experiment; the LightGBM curve shown gives a value of 22, so both the text and Table 3 are now adjusted to that curve. (ii) The ARIMA check for wind requested a one-step-ahead forecast for each horizon; when repeating the analysis with $h$-step forecasts, the wind descriptors remain unchanged. (iii) The row corresponding to PM$_{2.5}$ in the appendix on RMSE was derived from the same moving-average experiment and was recalculated ($H^*(\mathrm{strict})=23$).

\textbf{Additional experiments.} The new run of the ARIMA model for wind, the ARIMA order diagnosis, the RMSE recalculation (which exactly reproduces the reported MAE), and the sensitivity analysis to seasonal persistence used the same data and protocols as the original paper; no new class of model, hyperparameter, or data split was introduced.

\textbf{Data.} The exact input data from the four experiments, along with their SHA-256 checksums, are available at \url{https://github.com/EduIntellect/paper2H/tree/data-cache-v1/release/data_cache_four_domain}. Regarding the traffic series, whose underlying measurements come from Caltrans PeMS, we declare that we have not obtained independent confirmation of the redistribution terms and will remove the file if requested.
