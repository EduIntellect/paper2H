## 3. Data Integrity & Verification
To ensure all figures and tables stay aligned with the committed data, run the reconstruction pipeline:
```bash
# 1. Runs the post-processing script to rebuild the summary tables and figures
python3 src/rebuild_all_results.py

# 2. Runs the style-standardized conceptual figure generation script
python3 src/export_overleaf_figures.py
```
This guarantees that the files inside `figures/overleaf_export/` are directly generated from the CSV results versioned under `results/`.
